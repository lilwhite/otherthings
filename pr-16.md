## What

Pins the `maintenance` Azure CLI extension to **1.6.0** in the `local-exec` of `terraform_data.additional-dynamic-scope` (`mgt/core/update-manager/main.tf`). It is installed from the official package with `--source` instead of `--name maintenance`.

## Why

AB#349451. After installing the extension (previous PR), the apply failed on the next command:

```
terraform_data.additional-dynamic-scope["prd1Bifrost"] (local-exec): ERROR: 'create-or-update-subscription' is misspelled or not recognized by the system.
```

- With a recent Azure CLI, `az extension add --name maintenance` installs **1.2.1**, which only has `create`, `delete`, `list`, `list-parent` and `update`. It has no subscription-level (dynamic scope) commands.
- `create-or-update-subscription` is available in **1.6.0**, the latest stable version.
- `--version 1.6.0` fails on recent CLIs (`Version '1.6.0' not found`), so the package is installed by URL from `azcliprod.blob.core.windows.net/cli-extensions` (SHA-256 `3ab6a2dac48ba71b28bc8ee05d254daa72b62f84dda953749fa621a80ca39ae5`).

Verified locally with Azure CLI 2.87.0:
- 1.6.0 accepts all the arguments used by the resource.
- `--source … --upgrade` replaces an existing 1.2.1 and is idempotent.
- `terraform fmt -check` and `validate` succeed.

## Impact

- 1 line replaced and 1 comment added in `mgt/core/update-manager/main.tf`; only the new resource is changed.
- The failed resource is tainted, so the expected plan is **1 to add, 0 to change, 1 to destroy** (`terraform_data.additional-dynamic-scope["prd1Bifrost"]`). The destroy only removes it from the state.
- The apply creates the dynamic scope `Prd 1 - Monthly, Fourth Saturday at 02:00-DS` in `conp1glbsubbfrostaicx001` (2f267de7-e2c3-46e7-9d52-7adc9c97bd17).

## Follow-up

Add `maintenance` (1.6.0) to `azExtensions` in the UBC image (`CCoE-scb-infra-ubc`), so the install step is no longer needed.

## Rollback

Revert this PR. If the dynamic scope was already created, delete it:
`az maintenance assignment delete-subscription --name "Prd 1 - Monthly, Fourth Saturday at 02:00-DS" --subscription 2f267de7-e2c3-46e7-9d52-7adc9c97bd17`
